# Changelog

All notable changes to Adaptive Room Manager will be documented in this file.

## [0.1.0] - 2026-07-26

### Added

- Initial preview release.
- Global house configuration and room configuration based on Home Assistant areas.
- Temporary and persistent presence sources.
- Lux snapshot handling while managed lights are off.
- Binary and positional cover support.
- Day, evening, and night light groups.
- Generated diagnostic and configuration entities.
